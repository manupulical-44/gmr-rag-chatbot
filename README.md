# GMR AI Homes — Real Estate Chatbot

An AI-powered real estate assistant built with React and Groq AI. Ask about properties, prices, EMI calculations, home buying processes, and more — all through a clean chat interface.

## Live Demo

[https://gmr-chatbot-app.vercel.app](https://gmr-chatbot-app.vercel.app)

## Features

- **Property Search** — Find homes by budget, location, BHK preference, and size
- **Market Insights** — Understand pricing trends and neighbourhood data
- **Home Buying Help** — EMI calculations, legal documentation, and buying/renting guidance
- **Conversational Memory** — Maintains recent chat history for context-aware responses
- **Focused Scope** — Only answers real estate related questions

## Tech Stack

| Layer | Technology |
|-------|------------|
| Frontend | React 19, Vite, React Router |
| Styling | Tailwind CSS, Framer Motion |
| Icons | Lucide React |
| AI | Groq API (`llama-3.3-70b-versatile`) |
| HTTP | Axios |
| Deployment | Vercel |
